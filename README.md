## 🧠 Engineering Philosophy ##

For every challenge solved here, I focus on three main pillars:

- ***Correctness & Safety:*** Handling edge cases, validating inputs, and ensuring robust error management (e.g., handling malformed HTML).
- ***Efficiency:*** Optimizing Time and Space Complexity ($O(n)$ or better whenever possible).
- ***Readability:*** Following language-specific best practices (PEP 8 for Python, Java Naming Conventions, etc.).

## 🛠️ Stacks & Tools ##

I choose the tools that best fit the requirements of each specific challenge:

- ***Languages:*** Java (Core & JVM), Python, JavaScript.
- ***Environment:*** Docker, Git, Shell Script (zsh/bash).
- ***Methodologies:*** Clean Code, Big O Analysis, TDD (Test Driven Development).
