# 🚀 WebDev Challenge - User Management Dashborad

A high-fidelity implementation of a user management interface based on a specific design system. This project focusing on frontend architecture, responsive design, and interactive UI components.

## 🎯 Project Overview

The goal was to build a functional and responsive web page that mirrors a provided design. The interface allows administrators to manage user roles and contact information through a clean, modern dashboard.

## 🛠 Tecnologias Utilizadas

- ***React:*** For component-based UI development;
- ***Tailwind CSS:*** Utility-first CSS for precise styling and responsive utility classes;
- ***JavaScript:*** Component and state logic for interactivity;

## 🧠 Implementation Details

The project follows a modular component structure:
- ***Sidebar:*** A persistent navigation menu with active state management;
- ***Section:*** A reusable wrapper for collapsible cards, handling its own open/close state;
- ***app.jsx:*** The main orchestrator that manages form layout and global styling;
- ***Responsiveness:*** Adaptable layout for small and large screens;

## 🚀 Getting Started

1. Clone the repository:
    ```
    https://github.com/cdiasbrasilio/challengeAndTechnicalTests/tree/main/technicalAssessments/webDevChallenge_UserManagementInterface
    ```
2. Istalar as dependências:  
    ```
    npm install 
    ``` 
3. Iniciar o ambiente de desenvolvimento:  
    ```
    npm run dev
    ```
4. Aceder no navegador: Disponível em https://localhost:5173
